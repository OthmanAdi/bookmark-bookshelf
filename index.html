How reading works

When you add a link, paste the text you want to read with it. Pull the book off the shelf and that text opens as a clean page, at the paragraph where you stopped last time.

  • A link with text keeps your place, even after you close the browser.
  • A link without text opens with a field for the text and a button to the original page.
  • At the end of a text you can mark the link as read, and keep a private note beside it.
  • The app never loads the page behind a link. It shows only the text you gave it.

For a class

A teacher can put the reading for one assignment on a shelf and send it to the whole class. The shelf travels inside a file or a link, so no server ever holds it.

  1. Collect the reading

    Put the links for one assignment on a shelf, mark the optional ones and give the shelf a due date.

  2. Share the shelf

    Send it as a file or as a link. Without the texts, a shelf of links usually fits in a chat message.

  3. Students add it

    Opening the link shows what is on the shelf first. It arrives as a new shelf and changes nothing else.

  4. Hand in

    A plain-text summary lists what the student marked as read, ready to paste where the class hands in work. The app does not check it: it is what the student reports.

For developers

The app is four parts that never import each other. Each works on its own in plain TypeScript with no runtime dependencies.

Shelf
Draws the books for a given position and reports which one was chosen. Timing, gestures and storage live in the other parts.
Motion
Springs, drag, flick and snap on Pointer Events. It works for any row of items.
Store
A versioned library in local storage, with validation, migration, import and export.
Reader
Shows saved text as a page built from text nodes only, and reports the reading position.

Smaller combinations run on their own: the shelf with motion, the reader and the store.

The repository also carries an agent skill, so a coding agent can rebuild the whole shelf or one part with its contracts and checks. Add it with this command, then ask your agent for /bookshelf: 

npx skills add OthmanAdi/bookmark-bookshelf --skill bookshelf

The skill lives in .agents/skills/bookshelf/SKILL.md. Source on GitHub

Bookmark Bookshelf is an open-source 3D bookmark manager, released under the Apache-2.0 licence. It runs in your browser and has no server, so your links stay on your device.
